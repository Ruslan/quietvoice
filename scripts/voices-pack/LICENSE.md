# License & rights provenance — QuietVoice synthetic voice pack

**Short version:** every voice in this pack is an *output of an Apache-2.0 model, generated
from a text description only*. No real person's voice was recorded, sampled, or cloned. The
files are free to use, modify, and redistribute (including commercially), with no voice-
likeness / portrait-rights encumbrance.

## What these files are
`voice01.wav … voice10.wav` are speech generated by **Qwen3-TTS VoiceDesign**
(`Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`). VoiceDesign synthesises a *novel* voice matching a
natural-language description — it does **not** clone a reference recording. The only inputs to
this process were (a) the model weights and (b) plain text (a voice description + the sentence
to speak). See `generate-voices.py` (included) for the exact, re-runnable procedure.

## Why there is no voice-likeness / portrait-rights issue
- **No real recording is an input.** VoiceDesign builds the voice from a *description*, not from
  a person's audio. The Qwen documentation describes VoiceDesign voices as synthetic and not
  recordings of actual people (the DEV writeup titled *"Creating Rights-Free Voices with
  VoiceDesign"* summarises this: https://dev.to/tumf/qwen3-tts-surprised-by-the-quality-of-japanese-on-apple-silicon-m3-creating-rights-free-voices-k1d ).
- Because no identifiable person is captured, there is no publicity/portrait right to clear.
- Consent flags that apply to *voice cloning from a WAV* (e.g. crispasr's `--i-have-rights`)
  are **not applicable here** — this pack does no cloning from real audio.

## Reproducibility for auditors
Anyone can regenerate equivalent voices and confirm provenance end-to-end:
```bash
pip install -U qwen-tts soundfile
python generate-voices.py --out ./voices-out      # same script that produced this pack
```
The script pins the model id, the method (`generate_voice_design`), the 10 voice descriptions,
and the single spoken reference sentence. No hidden inputs; no real audio.
